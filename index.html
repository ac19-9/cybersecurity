What is Cryptographic Hashing?

Hashing turns any piece of data into a unique fixed-length "fingerprint". Forensic analysts hash every evidence file when they collect it — then hash it again later. If the two hashes match, the file was never changed. If they differ, someone tampered with the evidence.

What is a Hash?
A cryptographic hash is like a digital fingerprint for data. You feed in any text (or file), and the algorithm produces a fixed-length string of characters. The same input always produces the same hash. Change even one character, and the hash changes completely. Forensic analysts use hashes to verify that evidence files haven't been tampered with.
